## Stack

Plain HTML, CSS and JavaScript hosted on GitHub Pages. Data is stored in a Supabase (PostgreSQL) table `tasks` and accessed through the Supabase REST API with `fetch()` (GET, POST, PATCH, DELETE). The public configuration is in `config.json`; only the publishable key is used. The table setup is in `supabase-setup.sql`.
